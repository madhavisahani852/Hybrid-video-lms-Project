Authentication

All endpoints are unauthenticated by default — you can use them immediately with no API key. For premium features (AI scriptwriting via Gemini, higher Hugging Face queue priority), pass your keys in the request body or set them as environment variables on the server. See the apiKey, hfToken, and colabUrl optional parameters on individual endpoints.

GET /api/voices List available TTS voices
Returns the map of available Microsoft Edge neural TTS voices. These voices are used in the video generation pipeline to narrate your script. Each voice key follows the format language-REGION-NameNeural.

Request

No request body required. This endpoint is unauthenticated.

POST /api/generate-script Generate AI script from topic
Generates a complete video script, title, avatar prompt, and key takeaways from a topic. Uses Google Gemini 1.5 Flash if an API key is provided, otherwise falls back to a built-in template engine that works without any credentials.

Request Body

FieldTypeDescription
topic string The video topic (e.g. "5 productivity hacks") required
durationMinutes number Target video length in minutes. Default: 1. Supports: 0.5, 1, 2, 3.
targetAudience string Target audience for tone. Default: "general".
apiKey string optional Google Gemini API key. If not provided, uses server env var or template fallback.
curl 
curl -X POST {{BASE_URL}}/api/generate-script \
  -H 'Content-Type: application/json' \
  -d '{
    "topic": "AI video creation for beginners",
    "durationMinutes": 1,
    "targetAudience": "content creators"
  }'

Response 200 OK

JSON 
{
  "success": true,
  "title": "Mastering AI video creation for beginners in 1 Minute",
  "scriptText": "Welcome to today's quick update on AI video creation for beginners! ...",
  "avatarPrompt": "A confident modern professional presenter, photorealistic 8k portrait ...",
  "keyTakeaways": [
    "Key trends in AI video creation for beginners",
    "Automated zero-cost workflows",
    "High engagement content strategy"
  ]
}
POST /api/generate-avatar Generate AI presenter portrait
Generates a presenter portrait image from a text prompt using a 3-tier fallback system: Pollinations.ai (fast, free, no key) → Hugging Face FLUX (higher quality, needs HF token) → Procedural PNG (100% guaranteed, zero dependencies). The response includes the server-side path to the generated image.

Request Body

FieldTypeDescription
prompt string Text description of the presenter image. Default: professional tech presenter portrait. required
voice string optional Voice key to match avatar gender (auto-adjusts the prompt).
curl 
curl -X POST {{BASE_URL}}/api/generate-avatar \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "Professional tech presenter, studio lighting, hyperrealistic 8k portrait"
  }'

Response 200 OK

JSON 
{
  "success": true,
  "imagePath": "/app/tmp/avatar_1712345678901.png",
  "filename": "avatar_1712345678901.png"
}

POST /api/generate-video Start video generation pipeline
Triggers the full asynchronous video generation pipeline. The pipeline runs in the background: TTS → Audio Chunking → Talking-Head Rendering → FFmpeg Stitch. Returns a jobId immediately — poll GET /api/job-status/:jobId for progress.

Request Body

FieldTypeDescription
scriptText string The full spoken narration text. required
imagePath string Server-side path to the avatar image (from /api/generate-avatar or /api/upload-avatar). required
voice string TTS voice key from /api/voices. Default: "en-US-ChristopherNeural".
hfToken string optional Hugging Face token for higher GPU queue priority.
colabUrl string optional Custom Colab/Kaggle GPU worker endpoint.

Pipeline Stages

StageProgressDescription
TTS10–20%Convert script text to MP3 via edge-tts
Audio Chunk40%Split long audio into 20s segments
Talking-Head40–80%Each chunk sent to HF Space for lipsync
FFmpeg Stitch90%Concatenate clips + overlay master audio
Complete100%Final MP4 ready at finalVideoUrl

GET /api/job-status/:jobId Poll video generation progress
Poll the progress of an asynchronous video generation job. The response includes the current stage, percentage progress, and on completion a finalVideoUrl to download or stream the MP4. Poll every 2–3 seconds for a smooth user experience.

Path Parameters

End-to-End Example

A complete workflow to generate a talking-head video from scratch — no API keys required. Note: This example uses jq for JSON parsing — install it with apt install jq or brew install jq. Alternatively, use grep/sed to extract fields.

bash 
#!/bin/bash
BASE="{{BASE_URL}}"

# Step 1: Generate a script
SCRIPT=$(curl -s -X POST $BASE/api/generate-script \
  -H 'Content-Type: application/json' \
  -d '{"topic":"5 productivity hacks","durationMinutes":1}')
echo "$SCRIPT" | jq '.scriptText'

# Step 2: Generate an avatar
AVATAR=$(curl -s -X POST $BASE/api/generate-avatar \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"Professional tech presenter, studio lighting"}')
IMAGE_PATH=$(echo "$AVATAR" | jq -r '.imagePath')

# Step 3: Start video generation
JOB=$(curl -s -X POST $BASE/api/generate-video \
  -H 'Content-Type: application/json' \
  -d "{\"scriptText\": $(echo "$SCRIPT" | jq '.scriptText'), \"imagePath\": \"$IMAGE_PATH\"}")
JOB_ID=$(echo "$JOB" | jq -r '.jobId')

# Step 4: Poll until complete
while true; do
  STATUS=$(curl -s $BASE/api/job-status/$JOB_ID)
  echo "$STATUS" | jq '{stage, progress}'
  if [ "$(echo "$STATUS" | jq -r '.status')" = "completed" ]; then
    VIDEO_URL=$(echo "$STATUS" | jq -r '.finalVideoUrl')
    echo "Video ready: $BASE$VIDEO_URL"
    break
  fi
  if [ "$(echo "$STATUS" | jq -r '.status')" = "failed" ]; then
    echo "Failed: $(echo "$STATUS" | jq -r '.error')"
    break
  fi
  sleep 2
done
